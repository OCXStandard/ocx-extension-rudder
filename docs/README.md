# The ``ocx-extension-rudder`` documentation

## Schema XML documentation

The schema documentation is generated using [Altova XMLSpy](https://www.altova.com/xmlspy-xml-editor).
The generated HTML is not tracked in the repository. To produce it, open ``OCX_ext_rudder.xsd`` in XMLSpy and
generate the schema documentation into ``docs/XML/``.
